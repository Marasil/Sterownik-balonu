# Sterownik-balonu
Sterownik balonu oparty na ESP32-C3 Super Mini. Obsługuje efekty świetlne i dźwiękowe podczas przejazdu między stacjami A i B. Automatycznie wykrywa start i lądowanie, realizuje osobne sekwencje dla obu kierunków, umożliwia konfigurację przez Wi-Fi oraz przechodzi w Deep Sleep przy braku ładowania.
